# Iteration 01 — Teaching Practicum

High-school teaching-practicum version of the AI web-game class.

## Classroom model

- Three first-year high-school classes
- Team-based browser game projects
- Gemini-assisted HTML/CSS/JavaScript generation
- Planning → prompting → execution → testing → revision
- Teacher-facing lesson hub and class result pages

The lesson focused less on syntax-heavy programming and more on specifying game goals, rules, controls, feedback, and expected behavior, then evaluating AI-generated output.

## Reflection

The single-HTML workflow was fast and accessible, but requirements lived mainly inside prompts and team activity tended to concentrate around the code-generation step. Those limitations motivated the SPEC-driven redesign in Iteration 02.

Raw classroom submissions are not intended to be redistributed through the public repository.
