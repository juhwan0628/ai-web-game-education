# Iteration 02 — SPEC-driven Redesign

Second version of the AI web-game class, redesigned around a shared SPEC and role-based collaboration.

## Main changes

- Free-form prompting → SPEC-driven workflow
- Single HTML → project folder
- Code-only output → code, image, and audio assets
- Manual processing → validation and import scripts

## Workflow

1. Define the game idea.
2. Write README.md and SPEC.md.
3. Divide development, visual, and audio roles.
4. Produce assets in parallel.
5. Integrate against the SPEC.
6. Test in the browser.
7. Package the project.
8. Validate the submission.

## Highlights

- assets/js/: modular lesson UI
- templates/: reusable project templates
- scripts/: validation and import automation
- data/: result metadata

Raw team project folders are excluded from the public repository.
