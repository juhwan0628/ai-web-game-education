# Mini Battleground

## 팀 정보

- 팀 번호: 10팀
- 팀원: 예시 배치용
- 역할: 예시 배치용

## 게임 소개

한 줄 소개: 전장에서 살아남으며 적을 피하고 점수를 올리는 미니 배틀 게임

## 실행 방법

1. `index.html`을 브라우저로 연다.
2. 시작 버튼을 누른다.

## 조작법

- 이동: WASD 또는 방향키
- 조준: 마우스
- 스킬: 스페이스바
- 일시정지: P 또는 Esc

## 사용한 도구

- 기존 `/game/examples/mini-battleground/` 예시 게임을 임시 배치했다.
