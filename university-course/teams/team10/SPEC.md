# 게임 스펙 문서

## 1. 게임 개요

- 게임 제목: Mini Battleground
- 장르: 생존 액션
- 한 줄 소개: 전장에서 살아남으며 적을 피하고 점수를 올리는 미니 배틀 게임
- 핵심 재미: 이동, 회피, 성장, 점수 경쟁

## 2. 플레이 흐름

1. 시작 화면에서 게임을 시작한다.
2. 플레이어가 적을 피하고 전투하며 점수를 올린다.
3. 게임 오버 후 점수와 결과를 확인한다.

## 3. 화면 구성

- 시작 화면: 제목과 시작 버튼
- 게임 화면: 플레이 영역, 체력, 점수, 상태 정보
- 결과 화면: 최종 기록과 다시 시작

## 4. 조작법

- 이동: WASD 또는 방향키
- 공격 또는 상호작용: 마우스
- 기타: 스페이스바, P, Esc

## 5. 게임 규칙

- 플레이어가 할 수 있는 행동: 이동, 회피, 공격, 스킬 사용
- 적 또는 장애물의 행동: 플레이어를 추적하거나 공격
- 점수 획득 방식: 생존과 전투 결과
- 난이도 변화: 시간이 지나며 위험 증가

## 6. 승리 조건

가능한 오래 살아남고 높은 점수를 기록한다.

## 7. 패배 조건

체력이 0이 되면 게임 오버가 된다.
