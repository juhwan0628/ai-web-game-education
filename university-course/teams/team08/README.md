# 🎮 AI 협업 기반 게임 개발 프로젝트: 피키의 위험한 모험

## 🕹️ 게임 소개 및 실행 방법

### 1. 한 줄 요약
> 양갈래 핑크 머리를 가진 귀여운 주인공 피키(Piki)가 사악한 마법 숲속 마녀를 피해 도망치며, 다양한 장애물(선인장, 폭탄)을 뛰어넘고 유용한 아이템을 사용하여 살아남는 횡스크롤 RPG 러너 게임입니다.

### 2. 게임의 목표
* 60초의 제한 시간 동안 살아남아 각 스테이지를 클리어하고, 최고 점수(High Score)를 경신합니다!

### 3. 조작법 및 게임 룰
* **이동 조작**: 
  - `◀` `▶` (좌우 방향키)를 사용하여 플레이어의 앞뒤 위치를 조작합니다. (장애물이 날아올 때 정밀한 회피에 활용 가능)
  - `Spacebar` 또는 `▲` (위쪽 방향키)를 누르면 장애물을 뛰어넘는 점프를 수행합니다.
* **아이템 사용**: 
  - 스테이지 2와 3에서 공중에 등장하는 아이템을 획득하면 인벤토리에 장착됩니다.
  - 마우스로 오른쪽 하단의 **아이템 슬롯을 직접 클릭**하거나 키보드 **`Shift` 키**를 눌러 사용합니다.
  - **아이템 종류**:
    1. 🛡️ **보호막 (Shield)**: 장애물 또는 투사체 충돌을 1회 방어하며 일시적인 무적 상태를 부여합니다.
    2. ⏳ **시간 왜곡 (Time Warp)**: 5초 동안 게임의 모든 스크롤 속도와 장애물 속도를 느리게 만듭니다.
    3. ⚡ **폭발 (Pulse)**: 화면 상에 존재하는 모든 장애물과 적 투사체를 소멸시키고 추가 보너스 점수를 획득합니다.
* **체력 및 시스템 제약**:
  - 기본적으로 목숨은 1개입니다. 장애물과 충돌하면 즉시 게임오버가 됩니다. (보호막 버프가 있을 경우 보호막이 대신 소멸함)
  - 각 스테이지는 **60초** 동안 진행되며, 타이머가 0이 되면 스테이지가 성공적으로 클리어됩니다.
  - 게임의 배경은 시간 흐름에 따라 **0초 ~ 30초 구간은 낮**, **30초 ~ 60초 구간은 밤**으로 신비롭게 페이드 전환되며, 밤이 되면 숲속 몬스터 및 장애물의 출현 양상(낙하하는 파이어볼 등)이 더 격렬해집니다.
  - 최고 점수는 브라우저의 `localStorage`를 통해 스테이지별로 영구 저장됩니다.

## ⚒️ 사용한 AI 도구 및 기술 스택 (AI Stack)

* **프론트엔드 핵심 로직 및 인터페이스**: HTML5 Canvas API & Vanilla JS / CSS (Glassmorphism UI)
* **사운드 및 배경음악**: **Web Audio API 오디오 신디사이저**로 레트로 8비트 감성의 신스웨이브 BGM 및 효과음(점프, 아이템 획득, 폭발 등)을 실시간으로 직접 합성하여 재생합니다.
* **AI 보이스**: **Web Speech API (`speechSynthesis`)**를 사용하여 게임 시작 시 귀엽고 세련된 AI 캐릭터 보이스로 "Ready, Go!"를 출력합니다.
* **그래픽 디자인 및 애니메이션**: HTML5 Canvas의 2D 벡터 패스 그리기 기능을 활용하여 핑크색 양갈래 머리의 주인공 피키, 스크롤되는 다중 패럴랙스 마법 숲 배경, 화려한 폭발 이펙트와 보호막 글로우 등을 고화질로 부드럽게 렌더링합니다.
