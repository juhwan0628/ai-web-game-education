1. 게임 개요
- 게임 타이틀: 슈퍼개미
- 게임 장르: 회피 게임
- 게임 설명 (한 줄 요약): 
- 게임의 목표: 30초 후 가장 높은 주가 점수 받기

2. 게임 시스템 디자인
- 게임 진행 방식: 시작 화면 -> 게임 플레이 -> 결과창(30초 이후 주가 기록) -> 루프
- 게임 룰 (게임 규칙):
  - 조작법: 방향키로 이동
  - 점수/재화 획득 조건: 빨간 화살표를 먹으면 주식이 상승하고 파란 화살표를 먹으면 주식이 하락함.
  - 체력 및 목숨 시스템: 0이 되면 게임 오버
- 게임 인터페이스 (UI/UX):
  - 화면 크기: 가로 800 px x 세로 600 px
  - 화면 표시 정보: 현재 점수, 제한 시간 타이머

3. 캐릭터 및 시나리오
- 주요 캐릭터 소개 (캐릭터 콘셉트):
  - 플레이어(PC): 이름: 김개미 / 특징: 백수
- 스토리 개요 (시놉시스): 퇴직금을 영끌하여 삼전에 전재산 투자한 백수 김개미. 삼전이 떡상하길 기도하고 있다. 어느날, 하늘에서 화살표가 떨어지고 빨간 화살표를 먹었더니 삼전 주식이 오르기 시작한다! 
- 배경 설정: 2030년, 아주 평범한 날.

4. 게임 그래픽 아트 디자인 (디자인 파트 핵심)
- 캐릭터 디자인 (PC/NPC): 2D 도트 스타일의 인간형 개미
- 배경 디자인 (BGA): 주식차트
- 효과 디자인 (Effect): 아이템 획득 시 주식 그래프 오르내림

5. 게임 사운드 디자인 (오디오 디자인)
- 배경음악 (BGM): 플레이 중 - 웅장하고 긴박한 오케스트라 / 메인 화면 - 힘빠지는 우쿠렐레
- 효과음 (SFX): 빨간 화살표 먹을때- '딩동' 맑은 소리/파란 화살표 먹을때-'쿵'소리 / 게임오버 - '풍덩' 물에 빠지는 소리

6. 게임 플레이 테스트 계획
결과물을 조립한 후 완성도를 높이기 위한 디버깅 및 QA 계획입니다.

- 플레이 테스트 계획
  - 체크리스트: [ ] 조작감은 부드러운가? [ ] 난이도가 너무 불쾌하지 않은가? [ ] 버그로 멈추지 않는가?
- 게임 디버깅 계획:
  - 에러 발생 시 크롬 개발자 도구(F12) 콘솔 로그 확인
  - 해당 코드 블록과 문제 상황을 AI 에이전트에게 전달하여 코드 수정 진행

7. 게임 출시 및 마케팅 계획 (BM)
- 게임 가격 (비즈니스 모델): 무료 (근데 광고를 곁들인)
- 게임 마케팅 전략:
  - 타겟 유저: 학교 친구들 및 선생님
  - 홍보 방법: 교내 게시판에 QR 코드가 포함된 포스터 부착, AI 홍보 문구 생성 기능을 활용한 단체 채팅방 홍보
