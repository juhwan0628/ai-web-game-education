1. 게임 개요
- 게임 타이틀: 파도의 왕자 
- 게임 장르: 횡스크롤 로그라이크 핵 앤슬래시
- 게임 설명 (한 줄 요약): 스테이지마다 몬스터 제압 및 보스 토벌
- 게임의 목표: 최종 보스 격파

2. 게임 시스템 디자인
- 게임 진행 방식: 시작 화면(+강화창) -> 게임 플레이 -> 결과창(성공/실패) -> 루프 
- 게임 룰 (게임 규칙): 
  - 조작법: wasd로 이동, Spacebar로 아이템 사용, 마우스 좌클릭으로 공격, 우클릭으로 회피(돌진)
  - 점수/재화 획득 조건: 몬스터 처치 시 (몬스터 등급 별 차등 지급)
  - 체력 및 목숨 시스템: 기본 목숨 1개, 장애물 충돌 시 1개 감소, 0이 되면 게임 오버
- 게임 인터페이스 (UI/UX):
  - 화면 크기: 가로 [ 800 ] px x 세로 [ 600 ] px 
  - 화면 표시 정보: [ ] 현재 재화  [ ] 현재 스테이지 단계

3. 캐릭터 및 시나리오
- 주요 캐릭터 소개 (캐릭터 콘셉트): 서퍼(파도 타기)
  - 플레이어(PC): 아인/남자, 몸짱, 수영복
  - 적/방해물(NPC): 해산물, 보스는 대왕 오징어
- 스토리 개요 (시놉시스): 세상에서 제일 큰 파도를 찾아 여행을 떠난다. 하지만 바다는 만만치 않기에 다양한 바다 생물들과 환경이 장애물로 나타난다.
- 배경 설정: 21세기 태평양

4. 레벨 디자인 설계
- 스테이지 레벨 목록: 총 3 개 스테이지로 구성.
- 각 레벨의 목적과 특징:
  - LV 1 (튜토리얼): 목적 [기본 조작 익히기] / 특징 [장애물 속도 느림, 맵 단순함]
  - LV 2 (일반): 목적 [잡몹 ] / 특징 [장애물 속도 증가, 아이템 등장 시작]
  - LV 3 (보스/최종): 목적 [최종 보스 토벌(대왕 오징어) ] / 특징 [거대 장애물 등장, 패턴 다양화]

5. 게임 그래픽 아트 디자인 (디자인 파트 핵심)
- 캐릭터 디자인 (PC/NPC): 선글라스, 몸짱, 팬티 수영복
- 배경 디자인 (BGA): 한여름의 바다 
- 효과 디자인 (Effect): 아이템 획득 시 반짝이는 노란 이펙트, 충돌 시 화면 흔들림

6. 게임 사운드 디자인 (오디오 디자인)
- 배경음악 (BGM): 플레이 중 - 빠른 템포의 8비트 신스웨이브 음악 / 메인 화면 - 잔잔한 로파이
- 효과음 (SFX):  점프할 때 - '뿅' 소리 / 아이템 먹을 때 - '딩동' 맑은 소리 / 게임오버 - '콰광'
- 목소리 (Voice): 게임 시작 시 AI 보이스로 "Ready, Go!" 출력
