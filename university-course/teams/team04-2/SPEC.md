1. 게임 개요

- 게임 타이틀: 우주 고양이의 별 수집 대작전
- 게임 장르: 장애물 회피 액션 게임
- 게임 설명 (한 줄 요약):
  우주 고양이가 운석을 피해 별 에너지를 모으는 게임
- 게임의 목표:
  제한 시간 60초 동안 최대한 많은 별을 모아 최고 점수를 달성한다.

2. 게임 시스템 디자인

- 게임 진행 방식:
  시작 화면 → 게임 플레이 → 결과 화면 → 다시 시작
- 게임 룰 (게임 규칙):
  - 조작법: ← → 방향키로 이동
  - 점수 획득 조건: 별 1개 획득 시 10점
  - 체력 및 목숨 시스템:
    기본 체력 3개
    운석 충돌 시 체력 1 감소
    체력이 0이 되면 게임 오버
- 게임 인터페이스 (UI/UX):
  - 화면 크기: 800 × 600
  - 화면 표시 정보:
    현재 점수
    남은 체력
    제한 시간
    현재 스테이지

3. 캐릭터 및 시나리오

- 주요 캐릭터 소개
  - 플레이어(PC)
    이름: 코스모캣
    특징: 우주복을 입은 귀여운 고양이
  - 적/방해물(NPC)
    이름: 메테오
    특징: 빠르게 떨어지는 운석
- 스토리 개요
  은하 에너지 부족으로 위기에 빠진 우주를 구하기 위해 고양이 탐험가가 별 에너지를 수집한다.
- 배경 설정
  미래 우주 정거장과 은하 공간

4. 레벨 디자인 설계

- 스테이지 레벨 목록:
  총 3개 스테이지
- 각 레벨의 목적과 특징
  - LV1 (튜토리얼)
    목적: 기본 조작 익히기
    특징: 운석 속도 느림
  - LV2 (일반)
    목적: 점수 획득
    특징: 운석 증가, 별 등장 빈도 증가
  - LV3 (최종)
    목적: 최고 점수 달성
    특징: 거대 운석 등장, 장애물 속도 최대

5. 게임 그래픽 아트 디자인

- 캐릭터 디자인
  귀여운 2D 카툰 스타일의 우주복 고양이
- 배경 디자인
  별이 가득한 우주 배경과 행성
- 효과 디자인
  별 획득 시 황금색 반짝임 효과
  충돌 시 붉은 폭발 효과

6. 게임 사운드 디자인

- 배경음악 (BGM)
  경쾌한 우주 탐험 분위기의 전자음악
- 효과음 (SFX)
  별 획득: 딩!
  충돌: 쾅!
  게임 성공: 팡파레
  게임 오버: 뚜-
- 목소리 (Voice)
  "Ready!"
  "Go!"
  "Mission Complete!"

7. 게임 플레이 테스트 계획

- 플레이 테스트 계획
  ☑ 조작감 확인
  ☑ 난이도 확인
  ☑ 버그 확인
- 게임 디버깅 계획
  콘솔 로그 확인 후 수정

8. 게임 출시 및 마케팅 계획

- 게임 가격: 무료
- 게임 마케팅 전략
  - 타겟 유저:
    학교 친구 및 선생님
  - 홍보 방법:
    QR 코드 포스터 제작
    학교 단체 채팅방 홍보
    AI 제작 홍보 이미지 활용
