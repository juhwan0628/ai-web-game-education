- 게임 타이틀: 교실 파이터 (Classroom Fighter)
- 게임 장르: 2D 대전 격투 게임
- 게임 설명 (한 줄 요약): 방과 후 교실에서 펼쳐지는 학생들의 주먹다짐 대결!
- 게임의 목표: 상대방의 체력을 0으로 만들어 3판 2선승제로 승리하기

2. 게임 시스템 디자인
- 게임 진행 방식: 시작 화면 → 캐릭터 선택 → 스테이지 선택 → 게임 플레이(대전) → 결과창(승리/패배/무승부) → 루프
- 게임 룰 (게임 규칙):
  - 조작법: 방향키(←→)로 이동, ↑로 점프, Z키로 약공격, X키로 강공격, C키로 방어(가드)
  - 점수/재화 획득 조건: 라운드 승리 시 1점 획득, 퍼펙트 승리(체력 100% 유지) 시 보너스 2점 추가
  - 체력 및 목숨 시스템: 기본 체력 100HP, 공격 받을 때마다 감소(약공격 -10, 강공격 -25), HP가 0이 되면 해당 라운드 패배, 3판 2선승제로 먼저 2라운드 따는 플레이어가 최종 승리
- 게임 인터페이스 (UI/UX):
  - 화면 크기: 가로 800 px x 세로 600 px
  - 화면 표시 정보: [✅] 현재 점수(라운드 스코어) [✅] 남은 체력(HP 바) [✅] 제한 시간 타이머(라운드당 60초) [✅] 현재 라운드 단계

3. 캐릭터 및 시나리오
- 주요 캐릭터 소개 (캐릭터 콘셉트):
  - 플레이어(PC): [이름: 도현 / 특징: 컴공과 3학년, 빠른 발놀림과 연속 약공격이 특기인 민첩형 파이터]
  - 적/방해물(NPC): [이름: 철수 / 특징: 체육과 2학년, 느리지만 강공격 한 방이 치명적인 파워형 파이터]
- 스토리 개요 (시놉시스): 기말고사 직전, 학교 옥상 자판기 앞 마지막 캔 음료를 두고 벌어진 운명의 대결. 이긴 자만이 그 음료를 가져갈 자격이 있다.
- 배경 설정: 서기 2026년, 방과 후 아무도 없는 고등학교 교실 및 옥상

4. 레벨 디자인 설계
- 스테이지 레벨 목록: 총 3 개 스테이지로 구성.
- 각 레벨의 목적과 특징:
  - LV 1 (튜토리얼): 목적 [기본 이동·공격·방어 조작 익히기] / 특징 [상대 AI 반응 느림, 맵 단순한 교실 실내, 체력이 천천히 줄어듦]
  - LV 2 (일반): 목적 [콤보 공격 패턴 익히기] / 특징 [AI 반격 속도 증가, 맵에 책상 장애물 등장, 타이머 50초로 단축]
  - LV 3 (보스/최종): 목적 [모든 기술을 활용해 최강 라이벌 격파] / 특징 [보스 캐릭터 등장(담임 선생님), 강공격 패턴 다양화, 타이머 40초, 맵이 좁아지는 연출 추가]

5. 게임 그래픽 아트 디자인 (디자인 파트 핵심)
- 캐릭터 디자인 (PC/NPC): 2D 도트 스타일의 교복 입은 학생 캐릭터, 공격 시 만화풍 효과선(속도선) 연출, 보스는 선생님 교복+안경 착용
- 배경 디자인 (BGA): 스크롤 없는 고정 배경, LV1은 칠판·책상이 보이는 교실 내부, LV2는 복도, LV3는 저녁노을 옥상
- 효과 디자인 (Effect): 약공격 시 노란 별 이펙트, 강공격 시 붉은 충격파 + 화면 0.3초 흔들림, 방어 성공 시 파란 방패 반짝임, 라운드 승리 시 색종이 연출

6. 게임 사운드 디자인 (오디오 디자인)
- 배경음악 (BGM): 플레이 중 - 빠른 템포의 8비트 힙합 비트 / 메인 화면 - 긴장감 있는 로파이 브금 / 결과 화면 - 승리 시 경쾌한 팡파레, 패배 시 낮은 드럼 비트
- 효과음 (SFX): 약공격 - '퍽' 타격음 / 강공격 - '쾅!' 묵직한 충격음 / 방어 성공 - '챙!' 금속음 / 게임오버 - '콰지직' 무너지는 소리 / 라운드 시작 - 벨소리 효과음
- 목소리 (Voice): 라운드 시작 시 AI 보이스로 "싸워라!" 출력, 승리 시 "승리!", 패배 시 "아쉽군..."
