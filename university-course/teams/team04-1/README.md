# 🎮 AI 협업 기반 게임 개발 프로젝트: 교실 파이터 (Classroom Fighter)

## 🕹️ 게임 소개 및 실행 방법

### 1. 한 줄 요약
> 방과 후 교실에서 펼쳐지는 학생들의 마지막 음료 캔을 차지하기 위한 2D 고교 대전 격투 게임!

### 2. 게임의 목표
* 상대방의 체력을 0으로 만들어 라운드에서 승리하고, **3판 2선승제**로 최종 승리하여 기말고사 직전 옥상 자판기 앞 마지막 남은 탄산음료 캔을 차지하세요!

### 3. 조작법 및 게임 룰
* **기본 조작법:**
  * `←` / `→` (방향키): 좌우 이동
  * `↑` (방향키): 점프 (복도 스테이지의 책상 장애물을 뛰어넘을 수 있습니다)
  * `Z` 키: **약공격** (빠르게 타격, 데미지 10)
  * `X` 키: **강공격** (전방 돌진 무거운 일격, 데미지 25, 피격 시 화면 흔들림 및 붉은 충격파)
  * `C` 키: **방어 (가드)** (상대의 공격을 막아냅니다. 약공격 데미지 0, 강공격 데미지 5로 경감)
* **점수/재화 획득 조건:**
  * 라운드 승리 시 1점 획득
  * **퍼펙트 승리 (체력 100% 유지로 라운드 종료)** 시 보너스 2점 추가 획득
* **체력 및 시스템 제약:**
  * 기본 체력 100 HP. 0 HP 도달 시 라운드 패배.
  * 스테이지 레벨별 제한 시간: LV 1 (60초) / LV 2 (50초) / LV 3 (40초).
  * 제한 시간 종료 시 남은 체력(HP)이 더 높은 쪽이 라운드를 가져갑니다.

### 4. 실행 방법
1. `team01` 폴더 내의 `index.html` 파일을 Google Chrome 또는 Microsoft Edge 브라우저로 엽니다.
   * *더 안정적인 오디오 동작을 위해 로컬 웹 서버(예: `npx http-server` 또는 VS Code Live Server extension)를 사용하는 것을 권장합니다.*
2. 브라우저의 오디오 재생 정책으로 인해, 화면을 한 번 **클릭**하거나 키보드를 누르면 8비트 레트로 배경음악(BGM)과 음성 효과가 활성화됩니다.

## ⚒️ 사용한 AI 도구 (AI Stack)

* **코드 및 시스템 통합:** `Google Antigravity` (GDD 명세서를 분석하여 자율적으로 Canvas 게임 물리 엔진, AI 인텔리전스, 웹 사운드 합성 구현)
* **그래픽 디자인:** `나노바나나` 컨셉 (AI 이미지 생성기를 활용하여 스테이지별 고해상도 픽셀 아트 배경 및 캐릭터 초상화 일러스트 생성)
* **사운드 및 오디오:** Web Audio API & Web Speech API (브라우저 자체에서 8비트 사운드 신디사이저 동작을 정의하여 CORS 이슈가 없고 경량화된 retro BGM 및 타격음, 성우 목소리("싸워라!", "승리!") 구현)
