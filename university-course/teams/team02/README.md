# Assets File Names

게임 코드는 아래 로컬 파일명을 기준으로 이미 연결되어 있습니다.
실제 리소스가 완성되면 같은 경로와 파일명으로 교체하면 됩니다.

- `assets/images/enemy-smiler.png`

- `assets/images/enemy-boss.png`

- `assets/images/item-flashlight.png`

  - 배경음악

- `assets/audio/sliding-door.mp3`

- `assets/audio/fluorescent.mp3`
  - 형광등 깜빡임, 소리 장애물 반응 등에 쓰는 효과음
