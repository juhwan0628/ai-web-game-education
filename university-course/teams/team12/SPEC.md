## 1. 게임 개요

* 게임 타이틀: 그래비티 젤리
* 게임 장르: 모바일 캐주얼 물리 퍼즐 / 머지 퍼즐
* 게임 설명 한 줄 요약: 중앙 궤도를 도는 젤리를 떨어뜨리고, 4방향 중력을 바꿔 같은 색 젤리를 합치는 캐주얼 퍼즐 게임
* 게임의 목표: 같은 색 젤리를 합쳐 높은 단계의 젤리를 만들고, 최고 점수를 갱신하는 것

---

## 2. 게임 시스템 디자인

* 게임 진행 방식:
  시작 화면 → 게임 플레이 → 게임오버 결과창 → 다시 시작 루프

* 게임 룰 게임 규칙:

  * 중앙 궤도를 도는 젤리를 원하는 타이밍에 떨어뜨린다.
  * 같은 색 젤리 2개가 닿으면 다음 단계 젤리로 합쳐진다.
  * 중력을 위, 아래, 왼쪽, 오른쪽으로 바꿀 수 있다.
  * 중력을 바꾸면 방해물인 딱딱젤리가 생성된다.
  * 딱딱젤리 2개가 닿으면 서로 상쇄되어 사라진다.
  * 중앙 스폰 존이 일정 시간 이상 막히면 게임오버가 된다.
  * 빅딱딱젤리을 만들어도 게임은 끝나지 않고 계속 진행된다.

* 조작법:

  * PC: 방향키 또는 WASD로 중력 변경
  * PC: Spacebar 또는 Enter로 젤리 떨어뜨리기
  * 모바일: 짧게 터치하면 젤리 떨어뜨리기
  * 모바일: 스와이프하면 해당 방향으로 중력 변경

* 점수/재화 획득 조건:

  * 젤리가 합쳐져 새로운 단계의 젤리가 만들어질 때 점수를 획득한다.
  * 점수 배분:

    * 빨간 젤리: 1점
    * 주황 젤리: 3점
    * 노란 젤리: 8점
    * 초록 젤리: 20점
    * 파란 젤리: 50점
    * 남색 젤리: 120점
    * 보라 젤리: 280점
    * 무지개 젤리: 650점
    * 빅딱딱젤리: 2000점

* 체력 및 목숨 시스템:

  * 별도의 체력이나 목숨은 없다.
  * 중앙 스폰 존이 일정 시간 이상 막히면 게임오버가 된다.

* 게임 인터페이스 UI/UX:

  * 화면 크기: 정사각형 게임판 중심의 모바일 대응 화면
  * 화면 표시 정보:

    * 현재 점수
    * 다음 젤리 NEXT
    * 중력 변경 횟수 Moves
    * 중앙 스폰 존 위험 시간 Zone
    * 빅딱딱젤리 최초 생성 시간
    * 무지개 젤리 최초 생성 시간

## 3. 캐릭터 및 시나리오

* 주요 캐릭터 소개 캐릭터 콘셉트:

  * 플레이어 PC: 젤리를 떨어뜨리고 중력을 조작하는 플레이어
  * 적/방해물 NPC: 중력 변경 시 생성되는 돌멩이

* 스토리 개요:

  * 별도의 긴 스토리 없이, 젤리를 합쳐 더 높은 단계의 오브젝트를 만드는 캐주얼 퍼즐 게임으로 구성한다.

* 배경 설정:

  * 젤리들이 움직이는 정사각형 물리 퍼즐 공간

---

## 4. 레벨 디자인 설계

* 스테이지 레벨 목록: 단일 무한 반복형 스테이지로 구성

* 각 레벨의 목적과 특징:

  * 기본 플레이: 목적 기본 조작 익히기 / 특징 젤리를 떨어뜨리고 같은 색 젤리 합치기
  * 중반 플레이: 목적 높은 단계 젤리 만들기 / 특징 중력 변경과 돌멩이 관리가 중요해짐
  * 후반 플레이: 목적 무지개 젤리와 빅딱딱젤리 만들기 / 특징 큰 오브젝트가 공간을 차지하여 중앙 스폰 존 관리가 중요해짐

## 5. 게임 그래픽 아트 디자인 디자인 파트 핵심

* 캐릭터 디자인 PC/NPC:

  * 색깔별 원형 젤리 오브젝트
  * 단계가 높아질수록 크기가 커지고 색상이 변화함
  * 최종 오브젝트는 상징성이 큰 빅짱돌로 표현

* 배경 디자인 BGA:

  * 어두운 배경 위에 정사각형 게임판을 배치
  * 중앙 스폰 존과 궤도 원이 잘 보이도록 구성

* 효과 디자인 Effect:

  * 젤리 합성 시 점수 팝업 표시
  * 점수는 +숫자 형태로 출력
  * 딱딱젤리 2개가 사라질 때 파편 이펙트 출력
  * 중앙 스폰 존이 위험할 때 게임판 테두리가 빨간색으로 경고 표시
  * 게임오버 시 오브젝트가 터지는 연출 출력

## 6. 게임 사운드 디자인 오디오 디자인

* 배경음악 BGM:

  * 소리 없이도 플레이 가능한 캐주얼 퍼즐 게임을 목표로 한다.
  * 필요 시 가벼운 로파이 또는 미니멀한 배경음악을 사용할 수 있다.

* 효과음 SFX:

  * 젤리 합성 시 가벼운 팝 사운드
  * 돌멩이 상쇄 시 짧은 파편 사운드
  * 게임오버 시 짧은 실패 효과음

* 목소리 Voice:

  * 사용하지 않음

## 7. 게임 플레이 테스트 계획

결과물을 조립한 후 완성도를 높이기 위한 디버깅 및 QA 계획입니다.

* 플레이 테스트 계획

  * 체크리스트:

    * 조작감은 부드러운가?
    * 터치와 스와이프가 명확하게 구분되는가?
    * 중력 변경이 게임에 의미 있게 작동하는가?
    * 중앙 스폰 존 경고가 충분히 잘 보이는가?
    * 난이도가 너무 쉽거나 불쾌하지 않은가?
    * 젤리 합성 판정이 자연스러운가?
    * 점수 획득이 직관적으로 느껴지는가?
    * 게임오버 후 다시 시작이 정상적으로 되는가?

* 게임 디버깅 계획:

  * 에러 발생 시 크롬 개발자 도구 F12 콘솔 로그 확인
  * 해당 코드 블록과 문제 상황을 AI 에이전트에게 전달하여 코드 수정 진행
  * 모바일 환경에서 터치, 스와이프, 화면 비율 문제를 추가로 확인

## 8. 게임 출시 및 마케팅 계획 BM

* 게임 가격 비즈니스 모델:

  * 무료 플레이 기반으로 테스트

* 게임 마케팅 전략:

  * 타겟 유저:

    * 짧고 중독성 있는 퍼즐 게임을 좋아하는 사용자
    * 수박게임, 2048, 블록 퍼즐류를 좋아하는 사용자
    * 학교 친구들 및 수업 참여자

  * 홍보 방법:

    * 웹게임 링크 또는 QR 코드 공유
    * 친구들에게 최고 점수 경쟁 유도
    * “중력을 바꾸는 수박게임”이라는 짧은 문구로 소개
    * 플레이 화면을 짧은 영상으로 제작하여 공유
