# 🎮 그래비티 젤리 (Gravity Jelly)

AI 협업 기반으로 개발된 모바일 대응 캐주얼 물리 퍼즐 / 머지 퍼즐 게임 **'그래비티 젤리'**입니다.

---

## 🕹️ 게임 소개 및 실행 방법

### 1. 한 줄 요약
> 중앙 궤도를 도는 젤리를 떨어뜨리고, 4방향 중력을 바꿔 같은 색 젤리를 합쳐 나가는 중독성 높은 물리 머지 퍼즐 게임입니다.

### 2. 게임의 목표
* 같은 색 젤리들을 계속해서 더 높은 단계로 합성하여 **최종 단계인 '빅딱딱젤리(빅짱돌)'**를 만들어 내고, 최고 점수를 경신하는 것입니다.

### 3. 실행 방법
* 웹 브라우저에서 `index.html` 파일을 더블 클릭하여 실행하거나, 로컬 웹 서버(예: Live Server, `npm run dev` 등)를 통해 실행할 수 있습니다.
* 모바일 기기에서도 화면 비율이 자동으로 맞추어져 터치 및 스와이프 제스처로 쾌적하게 플레이할 수 있습니다.

### 4. 조작법 및 게임 룰
* **조작법 (PC):**
  * `Spacebar` 또는 `Enter`: 중앙 궤도에서 돌고 있는 젤리 떨어뜨리기 (타이밍이 중요!)
  * `방향키 (▲▼◀▶)` 또는 `WASD`: 중력 방향을 각각 상/하/좌/우로 변경
* **조작법 (모바일):**
  * `짧게 터치 (Tap)`: 젤리 떨어뜨리기
  * `스와이프 (Swipe)`: 스와이프한 방향으로 중력 변경
* **점수 획득 조건 (합성):**
  * 빨간 젤리: 1점
  * 주황 젤리: 3점
  * 노란 젤리: 8점
  * 초록 젤리: 20점
  * 파란 젤리: 50점
  * 남색 젤리: 120점
  * 보라 젤리: 280점
  * 무지개 젤리: 650점
  * **빅딱딱젤리 (최종 단계):** 2000점
* **게임 시스템 및 제약 (데드라인):**
  * **중앙 스폰 존 차단:** 젤리들이 중앙에 엉켜 스폰 존(중앙 점선 영역)이 **연속 3초 이상 막히면 게임오버**가 됩니다.
  * **중력 변경 페널티:** 중력을 변경하면 모든 젤리가 미끄러져 위치가 바뀌지만, 방해물인 **'딱딱젤리(돌멩이)'**가 중앙에 1개씩 추가 소환됩니다.
  * **돌멩이 소멸 기믹:**
    * 일반 딱딱젤리 2개가 부딪치면 서로 상쇄되어 사라집니다 (맵 정리 가능).
    * 무지개 젤리 2개를 합쳐 생성된 거대 방해물인 **빅딱딱젤리(빅짱돌)** 역시 또 다른 빅짱돌과 충돌하면 상쇄되어 소멸합니다.

## ⚒️ 사용한 AI 도구 (AI Stack)

* **코드 및 시스템 통합:** `Google Antigravity` (Matter.js 기반 물리 엔진, 커스텀 HTML5 Canvas 2D 렌더러, 자체 오디오 신디사이저, 모바일 조작계 통합 구현)
* **그래픽 디자인:** 자체 드로잉 엔진 (CSS 테마, Canvas 벡터 그래픽스를 통해 귀여운 표정, 눈알 굴리기, 젤리 충돌 찌그러짐 표현)
* **사운드 및 오디오:** Web Audio API 기반 오디오 합성기 (로파이 앰비언트 BGM 루프 및 젤리 투하, 합성, 폭발 SFX 생성)
