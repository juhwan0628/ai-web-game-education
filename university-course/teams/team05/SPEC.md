1. 게임 개요

* 게임 타이틀:스페이스 워
* 게임 장르: fps
* 게임 설명 (한 줄 요약):미래 지향적 sf 우주 배경 fps 각각의 우주군단이 전장에서 전투를 벌이는 게임
* 게임의 목표: 적군 지휘관 NPC 사살시 게임승리

2. 게임 시스템 디자인

* 게임 진행 방식: 시작 화면 -> 조작법 안내 -> 게임 플레이 -> 적군 NPC 전투 -> 적군 지휘관 NPC 등장 -> 결과창(성공/실패) -> 다시 시작
* 게임 룰 (게임 규칙):

  * 조작법: W, A, S, D로 이동, 마우스로 조준, 마우스 왼쪽 클릭으로 공격, Spacebar로 점프, R키로 재장전
  * 점수/재화 획득 조건: 일반 적군 NPC 처치 시 점수 획득, 정예 적군 NPC 처치 시 추가 점수 획득, 적군 지휘관 NPC 처치 시 최종 승리 점수 획득
  * 체력 및 목숨 시스템: 기본 체력 HP 100으로 시작하며, 적의 공격을 받으면 체력이 감소한다. 체력이 0이 되면 게임 오버가 되고, 회복 아이템을 획득하면 체력이 일부 회복된다.
* 게임 인터페이스 (UI/UX):

  * 화면 크기: 가로 [800] px x 세로 [600] px (추천: 800 x 600 또는 400 x 600)
  * 화면 표시 정보: [O] 현재 점수 [O] 남은 체력(HP) [O] 제한 시간 타이머 [O] 현재 스테이지 단계

3. 캐릭터 및 시나리오

* 주요 캐릭터 소개 (캐릭터 콘셉트):

  * 플레이어(PC): [이름: 카이든 / 특징: 은하연합 소속 특수부대원으로, 강화 슈트를 착용하고 우주 전장에서 임무를 수행하는 캐릭터]
  * 적/방해물(NPC): [이름: 제노스 군단 / 특징: 외계 군단 소속 병사들로, 플레이어를 발견하면 레이저 무기로 공격하며 최종 목표인 지휘관 NPC를 보호한다]
* 스토리 개요 (시놉시스):
  서기 2187년, 인류는 우주 식민지를 확장하던 중 외계 군단 제노스의 침공을 받게 된다. 플레이어는 은하연합의 특수부대원이 되어 적의 우주 전장에 침투하고, 제노스 군단을 지휘하는 적군 지휘관 NPC를 사살하여 전투를 승리로 이끌어야 한다.
* 배경 설정: 서기 2187년 은하 외곽의 거대 우주 전장과 외계 군단의 우주기지

4. 레벨 디자인 설계

* 스테이지 레벨 목록: 총 [3] 개 스테이지로 구성.
* 각 레벨의 목적과 특징:

  * LV 1 (튜토리얼): 목적 [기본 이동, 조준, 공격 방법 익히기] / 특징 [적의 수가 적고 공격 속도가 느리며 맵 구조가 단순함]
  * LV 2 (일반): 목적 [본격적인 전투 진행 및 적군 NPC 처치] / 특징 [적군의 수가 증가하고 장애물과 회복 아이템이 등장함]
  * LV 3 (보스/최종): 목적 [적군 지휘관 NPC 사살] / 특징 [강력한 지휘관 NPC가 등장하며 공격 패턴이 다양하고 제한 시간 안에 처치해야 함]

5. 게임 그래픽 아트 디자인 (디자인 파트 핵심)

* 캐릭터 디자인 (PC/NPC): 미래형 강화 슈트를 착용한 우주 특수부대원과 검은색, 붉은색 계열의 갑옷을 착용한 외계 군단 병사 디자인
* 배경 디자인 (BGA): 우주 함선 내부, 금속 통로, 네온 조명, 별이 보이는 창문, 파괴된 우주기지 등 SF 분위기의 배경
* 효과 디자인 (Effect): 레이저 총알 발사 효과, 피격 시 붉은 화면 효과, 폭발 효과, 지휘관 처치 시 강한 빛과 함께 승리 이펙트 출력

6. 게임 사운드 디자인 (오디오 디자인)

* 배경음악 (BGM): 플레이 중 - 빠른 템포의 SF 전투 신스 음악 / 메인 화면 - 긴장감 있는 우주 분위기의 전자 음악
* 효과음 (SFX): 총 발사 시 - 레이저 발사음 / 적 피격 시 - 금속 충격음 / 폭발 시 - 강한 폭발음 / 아이템 획득 시 - 짧고 맑은 전자음 / 게임오버 시 - 낮고 무거운 경고음
* 목소리 (Voice): 게임 시작 시 AI 보이스로 "Mission Start!" 출력, 적군 지휘관 등장 시 "Enemy Commander Detected!" 출력, 승리 시 "Mission Clear!" 출력

7. 게임 플레이 테스트 계획
   결과물을 조립한 후 완성도를 높이기 위한 디버깅 및 QA 계획입니다.

* 플레이 테스트 계획

  * 체크리스트: [O] 조작감은 부드러운가? [O] 난이도가 너무 불쾌하지 않은가? [O] 버그로 멈추지 않는가?
  * 추가 체크리스트: [O] 적군 NPC가 정상적으로 등장하는가? [O] 공격 판정이 정상적으로 작동하는가? [O] 체력과 점수가 올바르게 표시되는가? [O] 적군 지휘관 NPC 처치 시 승리 화면이 출력되는가?
* 게임 디버깅 계획:

  * 에러 발생 시 크롬 개발자 도구(F12) 콘솔 로그 확인
  * 해당 코드 블록과 문제 상황을 AI 에이전트에게 전달하여 코드 수정 진행
  * 조작, 공격, 체력 감소, 점수 증가, 승리/패배 조건을 각각 따로 테스트한 후 전체 게임을 통합 테스트한다.
