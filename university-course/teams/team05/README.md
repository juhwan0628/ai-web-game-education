# 🎮 AI 협업 기반 게임 개발 프로젝트: 스페이스 워 (Space War)

## 🕹️ 게임 소개 및 실행 방법

### 1. 한 줄 요약
> 서기 2187년, 침공한 외계 제노스 군단의 우주 전장에 침투해 정예 드론 유닛들과 최종 지휘관을 격파하는 Three.js WebGL 기반 고해상도 3D SF FPS 게임입니다.

### 2. 게임의 목표
* LV 1 훈련 구역과 LV 2 침투 구역을 정화하고, LV 3 최종 결전 구역에서 **90초의 제한 시간** 내에 보호막을 두른 **Xenos Commander(적 지휘관)**를 처치하여 인류를 구하십시오.

### 3. 조작법 및 게임 룰
* **조작법:**
  * `W`, `A`, `S`, `D` : 플레이어 이동 (앞, 뒤, 좌, 우)
  * `마우스 조준` : 3D 시점 회전 (화면을 클릭하면 포인터 잠금)
  * `마우스 왼쪽 클릭` : 플라즈마 레이저 발사
  * `Spacebar` : 점프
  * `R` : 플라즈마 에너지 탄창 재장전 (1.3초 소요)
  * `ESC` : 일시정지 및 마우스 고정 해제
* **점수/재화 획득 조건:**
  * LV 1 훈련용 드론 처치 시 : 각 100점 획득
  * LV 2 제노스 병사 드론 처치 시 : 각 300점 획득
  * LV 3 제노스 지휘관 처치 시 : 2000점 + 남은 시간 비례 보너스 점수 획득
* **체력 및 시스템 제약:**
  * 기본 HP 100 / Shield 50으로 시작합니다.
  * 피격 시 Shield가 먼저 충격파를 흡수하며, 3.5초 동안 공격받지 않으면 Shield가 서서히 자동 재생됩니다.
  * Shield가 모두 깨지면 HP가 감소하며, HP가 0이 되면 미션 실패(Game Over)합니다.
  * LV 2에서 드론을 처치하면 40% 확률로 녹색의 **생명 유지 힐팩(+35 HP)**이 드롭되어 접촉 시 즉시 획득합니다.
  * LV 3 보스전은 지휘관의 외곽 4개 실드 플레이트가 닫혀 있을 때는 데미지가 흡수되며, 실드가 외곽으로 개방되는 타이밍에 중앙의 하늘색 코어를 타격해야만 유효 데미지를 입힐 수 있습니다.

## ⚒️ 사용한 AI 도구 (AI Stack)

* **코드 및 시스템 통합:** `Google Antigravity` (Three.js 기반 WebGL 3D 엔진 설계 및 실시간 파티클, 머티리얼, 실드 회전 기하 연산 구현)
* **사운드 및 오디오:** `Suno` & Web Audio API (로컬 오디오 재생 제어 루틴 구축. 자동 재생 방지 정책을 우회하기 위해 사용자 시작/다시 시작 클릭 트리거에서 BGM 플레이, 게임 오버 시 BGM 즉시 일시정지 처리. 파일이 없을 경우를 대비해 Web Audio Synth 및 TTS 음성 백업 탑재)

## 📂 파일 및 폴더 구조

```text

 ├── index.html            # 게임 핵심 구동 파일 (Three.js WebGL 3D 렌더러 + 오디오 연동부 + HUD UI 통합본)

           ├── sfx_hit.mp3      # 적 피격/금속 타격음
           ├── sfx_explosion.mp3# 폭발 효과음
           ├── sfx_pickup.mp3   # 아이템 획득음
           ├── sfx_gameover.mp3 # 게임오버 경고음

           └── voice_win.mp3    # 승리 아나운싱 보이스 (Mission Clear!)
```

## 🚀 실행 방법
1. 브라우저에서 `index.html` 파일을 바로 엽니다. (별도의 웹 서버나 설치 과정 없이 Chrome, Edge 등의 모던 웹 브라우저에서 로컬 파일 기준으로 완벽히 실행됩니다.)
2. 마우스를 화면 중앙의 **"전투 시작"** 버튼에 올리고 클릭하면 전체 오디오 활성화와 함께 첫 스테이지가 시작됩니다.
