1. 게임 개요
- 게임 타이틀: 비둘기 헬리콥터
- 게임 장르: 횡스크롤 RPG
- 게임 설명 (한 줄 요약): 비둘기 헬리콥터를 이용한 횡스크롤 모험
- 게임의 목표: 장애물을 피해서 목적지까지 시간을 재고 도달하기

2. 게임 시스템 디자인
- 게임 진행 방식: 시작 화면 -> 게임 플레이 -> 결과창(성공/실패) -> 루프
- 게임 룰 (게임 규칙):
  - 조작법: 방향키로 이동
  - 점수/재화 획득 조건: 목적지 달성
  - 체력 및 목숨 시스템: 화면 밖으로 나가면 게임 오버, 장애물 맞으면 게임 오버
- 게임 인터페이스 (UI/UX):
  - 화면 크기: 가로 800 px x 세로 600 px
  - 화면 표시 정보: 시간 타이머

3. 캐릭터 및 시나리오
- 주요 캐릭터 소개 (캐릭터 콘셉트):
  - 플레이어(PC): 머리로 돌아가는 비둘기
  - 적/방해물(NPC): 장애물은 4호선 : 손잡이 , 2호선 : 고양이,1호선 : 단소아저씨 이미지로
- 스토리 개요 (시놉시스): 머리로 돌아가는 비둘기가 단소아저씨를 피해서 새우깡에 도달하면 엔딩
- 배경 설정: 지하철

4. 레벨 디자인 설계
- 스테이지 레벨 목록: 총 3 개 스테이지로 구성.
- 각 레벨의 목적과 특징:
  - LV 1 (튜토리얼): 4호선 배경, 목적 [기본 조작 익히기] / 특징 [장애물 속도 느림, 맵 단순함]
  - LV 2 (일반): 목적 2호선 배경, / 특징 [장애물 속도 증가, 아이템 등장 시작]
  - LV 3 (보스/최종): 1호선 배경, 목적 [단소할아버지 피해서 하기 ] / 특징 [거대 장애물 등장, 패턴 다양화]

5. 게임 그래픽 아트 디자인 (디자인 파트 핵심)
- 캐릭터 디자인 (PC/NPC): 비둘기 헬리콥터/ 손잡이(4호선 장애물), 고양이(2호선 장애물), 단소 아저씨(1호선 장애물)
비둘기 이미지를 제공하면 머리가 돌아가며 헬리콥터처럼 날아다닌다.
- 배경 디자인 (BGA): 동일한 지하철 배경을 사용하되,  4, 2, 1호선의 숫자 및 색으로 스테이지 레벨 구분을 한다.창문 밖의 배경을 통해 지하철이 지나가는 느낌을 준다.
- 효과 디자인 (Effect): 충돌 시 떨어지며 사망, END 이펙트

6. 게임 사운드 디자인 (오디오 디자인)
- 배경음악 (BGM): [플레이 중 - 빠른 템포의 8비트 음악 + 드럼]
- 효과음 (SFX): [올라갈 때, 헬리콥터 돌아가는 소리, 내려갈때 힘빠지는 소리]
- 목소리 (Voice): [게임 시작 시 레이싱 게임 스타트처럼 3 2 1 소리 내기]
