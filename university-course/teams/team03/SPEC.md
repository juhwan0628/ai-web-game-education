1. 게임 개요

• 게임 타이틀: 캠퍼스 런: 마감 탈출

• 게임 장르: 스포츠 캐주얼 게임 / 횡스크롤 러닝 게임

• 게임 설명 (한 줄 요약): 과제 마감에 쫓기는 학생이 캠퍼스를 달리며 장애물을 피하고 아이템을 모아 최고 점수를 기록하는 게임이다.

• 게임의 목표: 제한 시간 60초 동안 장애물을 피하며 최대한 오래 생존하고, 커피와 노트 아이템을 획득하여 최고 점수를 갱신하는 것이 목표이다.

2. 게임 시스템 디자인

• 게임 진행 방식: 시작 화면 ➔ 게임 설명 화면 ➔ 게임 플레이 ➔ 결과창(성공/실패) ➔ 다시 시작 루프

• 게임 룰 (게임 규칙):

o 조작법: 방향키 또는 A/D 키로 좌우 이동하고, Spacebar로 점프한다.

o 점수/재화 획득 조건: 게임 시간이 지날수록 기본 점수가 증가하며, 화면에 등장하는 커피 아이템과 노트 아이템을 획득하면 추가 점수를 얻는다. 커피 아이템은 10점, 노트 아이템은 20점으로 설정한다.

o 체력 및 목숨 시스템: 기본 체력은 HP 3칸으로 시작한다. 장애물과 충돌할 때마다 HP가 1칸 감소하며, HP가 0이 되면 게임 오버가 된다. 제한 시간 60초 동안 생존하면 게임 클리어로 판정한다.

• 게임 인터페이스 (UI/UX):

o 화면 크기: 가로 [800] px × 세로 [600] px

o 화면 표시 정보: [O] 현재 점수 [O] 남은 체력(HP) [O] 제한 시간 타이머 [O] 현재 스테이지 단계

3. 캐릭터 및 시나리오

• 주요 캐릭터 소개 (캐릭터 콘셉트):

o 플레이어(PC): [ 이름: 마감이 / 특징: 과제 제출 시간을 앞두고 캠퍼스를 달리는 대학생 캐릭터이다. 후드티와 백팩을 착용한 친근하고 귀여운 2D 캐주얼 캐릭터로 표현한다. ]

o 적/방해물(NPC): [ 이름: 졸음 구름, 과제 폭탄, 지각 시계 / 특징: 플레이어의 이동을 방해하는 장애물이다. 졸음 구름은 천천히 떠다니고, 과제 폭탄은 바닥에 놓여 있으며, 지각 시계는 빠르게 움직여 플레이어의 회피를 어렵게 만든다. ]

• 스토리 개요 (시놉시스): 평화로운 캠퍼스의 어느 날, 주인공 마감이는 과제 제출 시간이 얼마 남지 않았다는 사실을 깨닫는다. 마감이는 캠퍼스 곳곳에 놓인 장애물을 피하고 커피와 노트를 모으며 제한 시간 안에 과제를 제출하기 위해 달린다.

• 배경 설정: 2026년 대학 캠퍼스를 배경으로 하며, 강의동 앞길, 도서관 입구, 과제 제출 포털 공간을 차례로 지나가는 밝고 캐주얼한 분위기로 구성한다.

4. 레벨 디자인 설계

• 스테이지 레벨 목록: 총 [3] 개 스테이지로 구성.

• 각 레벨의 목적과 특징:

o LV 1 (튜토리얼): 목적 [기본 조작 익히기] / 특징 [장애물 속도 느림(초당 2px), 맵 단순함, 커피 아이템이 자주 등장하여 조작에 익숙해질 수 있음]

o LV 2 (일반): 목적 [장애물 회피와 아이템 수집에 익숙해지기] / 특징 [장애물 속도 증가, 노트 아이템 등장 시작, 장애물 간격이 좁아져 점프 타이밍이 중요해짐]

o LV 3 (보스/최종): 목적 [제한 시간까지 생존하기] / 특징 [거대 장애물 등장, 패턴 다양화, 빠르게 움직이는 지각 시계와 과제 폭탄이 함께 등장하여 난이도가 상승함]

5. 게임 그래픽 아트 디자인 (디자인 파트 핵심)

• 캐릭터 디자인 (PC/NPC): 플레이어 캐릭터는 2D 캐주얼 도트 스타일의 대학생으로 디자인한다. 후드티, 백팩, 운동화를 착용한 친근한 모습으로 표현하며, NPC 장애물은 과제 폭탄, 졸음 구름, 지각 시계처럼 학교생활과 관련된 상징적인 오브젝트로 제작한다.

• 배경 디자인 (BGA): 밝은 색감의 대학 캠퍼스 배경을 사용한다. 강의동, 나무, 벤치, 도서관 입구 등이 보이도록 구성하고, 게임 진행에 따라 배경이 좌우로 스크롤되는 느낌을 준다.

• 효과 디자인 (Effect): 아이템 획득 시 반짝이는 노란 이펙트를 표시한다. 장애물과 충돌하면 화면이 짧게 흔들리고 캐릭터가 깜빡이는 효과를 넣는다. 게임 클리어 시에는 별 모양 파티클이 나타나도록 한다.

6. 게임 사운드 디자인 (오디오 디자인)

• 배경음악 (BGM): 메인 화면에서는 잔잔하고 밝은 로파이풍 음악을 사용한다. 게임 플레이 중에는 빠른 템포의 8비트 신스팝 음악을 사용하여 달리는 느낌과 긴장감을 준다. 결과창에서는 성공 시 경쾌한 음악, 실패 시 짧고 아쉬운 느낌의 음악을 재생한다.

• 효과음 (SFX): 점프할 때는 ‘뿅’ 하는 짧은 효과음을 사용한다. 아이템을 먹을 때는 ‘딩동’ 또는 ‘띠링’ 같은 맑은 소리를 사용한다. 장애물과 충돌할 때는 ‘퍽’ 또는 ‘쿵’ 소리를 사용하고, 게임오버 시에는 낮은 톤의 ‘두둥’ 효과음을 사용한다.

• 목소리 (Voice): 게임 시작 시 AI 보이스로 “Ready, Go!”가 출력되도록 한다. 게임 클리어 시에는 “과제 제출 성공!”이라는 음성이 나오고, 게임오버 시에는 “마감 실패!”라는 음성이 나오도록 설정한다.

7. 게임 플레이 테스트 계획

결과물을 조립한 후 완성도를 높이기 위한 디버깅 및 QA 계획입니다.

• 플레이 테스트 계획

체크리스트: [O] 조작감은 부드러운가? [O] 난이도가 너무 불쾌하지 않은가? [O] 버그로 멈추지 않는가? [O] 점수와 HP가 정상적으로 표시되는가? [O] 제한 시간이 정상적으로 감소하는가? [O] 아이템 획득과 장애물 충돌 판정이 자연스러운가? [O] 게임오버와 클리어 화면이 정상적으로 출력되는가?

• 게임 디버깅 계획: 에러 발생 시 크롬 개발자 도구(F12) 콘솔 로그를 확인한다. 이후 충돌 판정, 점수 증가, 타이머 감소, 화면 전환 부분을 우선적으로 점검한다. 문제가 발생한 코드 블록과 문제 상황을 AI 에이전트에게 전달하여 즉각적인 리팩토링 및 코드 수정을 진행한다. 수정 후에는 같은 상황을 반복 테스트하여 오류가 해결되었는지 확인한다.
